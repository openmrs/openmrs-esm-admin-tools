# Metadata Export Module

`openmrs-esm-metadataexport-app` is a frontend module for O3 that provides tools to manage and export metadata packages.

## Setup

See the guidance in the [Developer Documentation](https://o3-docs.openmrs.org/docs/frontend-modules/development#installing-dependencies).

This repository uses Yarn.

To run a dev server for this package, run

```bash
yarn start --sources 'packages/esm-metadataexport-app'
```
